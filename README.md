# Yahav Store — אתר דרופשיפינג מוכן ל-GitHub Pages

זהו אתר סטטי מוכן לפרסום ב-GitHub Pages.

## מה יש באתר
- עיצוב רספונסיבי למחשב ולטלפון
- קטלוג מוצרים
- סינון לפי קטגוריות
- עגלת קניות
- שינוי כמויות והסרת מוצרים
- קופון `YAHAV10`
- שמירת עגלה ב-localStorage
- מצב כהה
- FAQ
- טופס הרשמה דמו
- Checkout דמו בלבד

## חשוב
GitHub Pages תומך באתר סטטי. הוא **לא** מעבד תשלומים אמיתיים ולא מריץ קוד שרת כמו PHP/Python.

כדי להפוך את החנות למסחרית אמיתית:
1. החלף את מוצרי הדוגמה במוצרים שלך.
2. החלף תמונות, מחירים ותיאורים בקובץ `script.js`.
3. החלף את פרטי יצירת הקשר ב-`index.html`.
4. הוסף מדיניות משלוחים, החזרות, פרטיות ותנאי שימוש.
5. חבר שירות סליקה מאובטח חיצוני.
6. אל תשמור מספרי אשראי או מידע סודי בקבצי האתר.

## איך מפרסמים ב-GitHub Pages
1. צור Repository חדש ב-GitHub.
2. העלה את כל הקבצים שבתיקייה הזו ל-root של ה-Repository.
3. ודא שהקובץ `index.html` נמצא בשורש.
4. היכנס ל-Settings -> Pages.
5. תחת Build and deployment בחר `Deploy from a branch`.
6. Branch: `main`.
7. Folder: `/(root)`.
8. לחץ Save.

לאחר הפרסום GitHub יציג לך את כתובת האתר.
