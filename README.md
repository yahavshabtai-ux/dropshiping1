## חשוב
ההתאמות לדגמי הטלפון משוערות לפי התמונות בלבד. מומלץ לאשר דגם מדויק לפני מכירה.

## העלאה ל-GitHub
1. חלץ את ה-ZIP.
2. העלה את `index.html`, `style.css`, `script.js` ואת התיקייה `assets` לשורש ה-Repository.
3. אם GitHub שואל על קבצים קיימים, העלה/החלף אותם בגרסה החדשה.
4. GitHub Pages יתעדכן לאחר ה-commit וה-deploy.

האתר הוא Front-End דמו. אין בו סליקה אמיתית.
