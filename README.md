# Yahav Store V2 — Premium UI

גרסה משודרגת של אתר הדמו.

## מה חדש
- עיצוב כהה פרימיום עם Glow ו-Glass
- Hero חדש לחלוטין
- מוצר Featured עם אנימציות
- כרטיסי מוצר חדשים
- Quick View
- חיפוש מוצרים
- קטגוריות
- עגלת קניות משופרת
- פס התקדמות למשלוח חינם
- קופון YAHAV10
- מצב בהיר/כהה
- Responsive למובייל
- FAQ, Reviews, Newsletter
- localStorage לעגלה ולקופון

## העלאה ל-GitHub
החלף את הקבצים הישנים ב:
- index.html
- style.css
- script.js
- assets/favicon.svg

ודא שהקבצים נמצאים בשורש ה-Repository.

## חשוב
זהו Front-End דמו בלבד. אין סליקה אמיתית.
אל תשמור פרטי אשראי, סיסמאות או API keys בתוך הקוד.
